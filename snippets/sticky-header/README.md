# sticky-header

**Replaces:** sticky header / sticky menu plugins used only to pin the site header to the top on scroll.

**Covers:** pinning the header, keeping it above content, a small shadow once scrolled (optional).

**Doesn't cover:** shrink-on-scroll animations, a different logo when stuck, hide-on-scroll-down behaviour, per-page toggles. If you used any of those, keep the plugin or write the few lines of JS yourself.

**Tested on:** WordPress 6.9, classic theme with a `.site-header` element, October 2026. Change the selector to match your theme (`header`, `#masthead`, `.site-header` are the common ones).
